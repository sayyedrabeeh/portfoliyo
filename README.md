# Portfolio Website (HTML, CSS & JavaScript)

A modern and responsive **portfolio website** built using HTML, CSS, and JavaScript.  
This site showcases my skills, projects, and experience as a **Full Stack Developer**, with a fully functional **contact form** that sends messages directly to my email.

🌐**Live Demo:** [https://sayyedrabeeh.github.io/portfoliyo/](https://sayyedrabeeh.github.io/portfoliyo/)

---

##  About the Project
This portfolio is designed using a professional template and customized to reflect my personal brand.  
It provides visitors with an easy way to explore my work, learn about my expertise, and reach out through a direct contact form.

---

##  Features
- Responsive design for all screen sizes  
- Smooth navigation and modern animations  
- Project and skills showcase section  
- **Working contact form** (Name, Email, Message) — emails are sent via integrated web form service  
- Clean and minimalistic UI for a professional look  

---

##  Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript**  
- **Web Form API** (for handling contact form submissions)
